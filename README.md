# AccessView

AccessView is an accessibility-focused web application designed to support communication and awareness through live captions, translation, conversation assistance, sound alerts, and reminders.

## Features

- 🎙️ Live Captions & Translation
- 💬 Person A / Person B Conversation
- 🌐 Multilingual Speech Translation
- 🔊 Visual Sound Alerts
- ⏰ Persistent Reminders
- ⚙️ Accessibility Settings
- 🌙 Light & Dark Mode
- 🌍 English, Telugu & Hindi UI

## Supported Languages

### Speech & Translation
- English
- Telugu
- Hindi
- Tamil
- Malayalam
- Marathi
- Bengali

### Application Interface
- English
- Telugu
- Hindi
